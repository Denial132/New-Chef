# 👨‍🍳 New Chef Game

A 2D cooking game bult using **Python and Pygame**. 

## 🎮 Features

* Supplier tablet
* Unlockable fryers, grills, and drink dispensers
* Taking orders
* Delivery system
* Settings menu:

  * Changing volume using a volume slider


## 🕹️ Controls

|     Key    |         Action        |
| ---------- | ----------------      |
| Number Keys|    Change the area    |
|      Q     |Use grill 1, or Fryer 1|
|      W     |Use grill 2, or Fryer 2|
|      E     |Use grill 3, or Fryer 3|
|      R     |Use grill 1, or Fryer 4|
|      A     |      Use grill 5      |
|      S     |      Use grill 6      |
|      D     |      Use grill 7      |
|      F     |      Use grill 8      |
|      D     |    Use Dispenser 1    |
|      F     |    Use Dispenser 2    |
|      G     |    Use Dispenser 3    |
|      H     |    Use Dispenser 4    |




## 📦 How to Play

### Windows

1. Download the latest release.
2. Run `New Chef.exe`.
3. Start playing!

No Python or Pygame installation is required.

## 💾 Save System

The game automatically saves:

* When served a customer
* Pressing the S key
 
## 💾 Loading game
* Pressing the L key


Your save file (`save.json`) is created automatically when the game runs.
